# Эксплуатация

## Штатная публикация

1. Проверьте статус `pylint` в Pull Request.
2. Выполните слияние в `main`.
3. В Actions откройте Publish documentation.
4. Дождитесь завершения `build` и `deploy`.
5. Проверьте главную страницу по URL окружения `github-pages`.

## Ручной перезапуск

Выберите Publish documentation → Run workflow.

## Диагностика

Определите отказавший этап и прочитайте журнал соответствующего шага.
